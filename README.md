## Deskripsi Program
Program berbasis konsol (terminal) menggunakan Python ini dirancang sebagai alat bantu belajar bagi siswa SMP kelas VII untuk menghitung luas dan keliling bangun datar, yaitu persegi, persegi panjang, segitiga, dan lingkaran.
Program dirancang untuk menampilkan rumus dan langkah perhitungan, memvalidasi input pengguna, serta menyimpan dan menampilkan riwayat perhitungan melalui file teks.

## Fitur Program
1. Memilih bangun datar melalui menu.
2. Menghitung luas, keliling, atau keduanya.
3. Menampilkan rumus dan langkah perhitungan.
4. Memvalidasi input pengguna.
5. Menyimpan dan menampilkan riwayat perhitungan.

## Struktur Folder Proyek
- `src/` : Berisi kode sumber utama Python, yaitu `main.py`, `geometri.py`, `validasi.py`, dan `data_io.py`.
- `tests/` : Berisi dokumen skenario pengujian program (`test_case.md`).
- `output/` : Digunakan untuk menyimpan riwayat hasil perhitungan setelah program dijalankan.

## Cara Menjalankan Program
1. Pastikan Python sudah terinstal di komputer.
2. Buka folder proyek melalui VS Code.
3. Buka terminal di VS Code.
4. Jalankan perintah berikut:

   ```bash
   python src/main.py
   ```

**Catatan:** Perintah tersebut dapat digunakan setelah program selesai diimplementasikan pada Pertemuan 15.

## Pengujian
Pengujian dirancang menggunakan kasus normal, batas, dan input tidak valid. Daftar skenario pengujian terdapat pada file `tests/test_case.md`.
